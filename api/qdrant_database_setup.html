Create and prepare the Qdrant collection used for sentence embeddings.

qdrant_database_setup.setup_qdrnt.main() → None[source]

Create the Qdrant collection and disable automatic indexing for bulk load.

The collection is created once, with a cosine-distance vector configuration matching the S-BioBERT embedding dimension. Automatic indexing is disabled to speed up the initial bulk insert phase, after which indexing can be turned back on for query performance.

Module contents

Qdrant collection setup and maintenance utilities.

This package contains the initialization logic for creating the vector collection used to store PubMed sentence embeddings and for disabling or re-enabling indexing during bulk upload and search phases.
