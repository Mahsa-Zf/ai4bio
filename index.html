Ai4Bio documentation

This project prepares PubMed text for semantic search by splitting abstracts into sentences, storing them in MySQL, encoding them with a biomedical sentence transformer, and querying the resulting embeddings in Qdrant.

Package overview

  • embedding: loads sentence rows, encodes them into vectors, and uploads them to the vector database.

  • qdrant_database_setup: creates and configures the Qdrant collection for bulk embedding uploads.

  • query: embeds a query string and searches for similar sentences in Qdrant.

  • sql_database_setup: parses TSV records and inserts sentence rows into the database.
